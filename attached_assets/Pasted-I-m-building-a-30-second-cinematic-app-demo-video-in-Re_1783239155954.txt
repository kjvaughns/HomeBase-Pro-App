ANIMATION RULES (enforce strictly):
- Every entrance uses spring() from remotion, never CSS transition or keyframe
- interpolate() for opacity: interpolate(frame, [startF, startF+18], [0, 1], { extrapolateRight: 'clamp' })
- Text: translateY spring from +14→0, opacity 0→1
- Cards: translateY spring from +20→0, stagger 8f each
- Phone: translateY spring from +80→0 on enter, reverse on exit
- Toast: translateY spring from -30→0 on enter
- Scene cross-fades: opacity interpolate over 20 frames at scene boundaries
- Checkmark/badge: scale spring from 0→1.2→1 (overshoot feel)
- Never use Math.random() — Remotion must be deterministic
